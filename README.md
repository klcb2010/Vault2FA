# Vault2FA 魔改版

基于原版 Vault2FA 进行功能调整与增强，当前魔改版本：**2.9.4**。

## 魔改内容

### 1. WebDAV 云端同步

将原有同步方式替换为 WebDAV，用户可使用自己的 WebDAV 服务保存加密保险库：

- 支持填写 WebDAV 服务器地址、用户名和密码，登录后即可使用同步功能。
- 本地保险库开启加密后，才允许上传同步数据；上传到 WebDAV 的是加密后的保险库内容。
- **自动同步**：本地新增、编辑或删除验证码后，自动将最新的加密保险库上传到云端。
- **立即上传**：手动将当前本地保险库上传，并覆盖云端备份。
- **立即下载**：手动下载云端备份并覆盖本地保险库，覆盖前会弹出确认提示。
- 提供 WebDAV 登录与退出登录、自动同步开关，以及最近上传和下载状态信息。
- 登录后密码框以掩码形式显示，避免直接展示已保存的密码。

> 注意：自动同步会同步删除操作，云端备份也会随之更新，因此自动同步不能用于恢复误删的验证码。需要恢复时，应使用仍保留旧数据的其他设备或独立备份。

### 2. 仅显示当前网站验证码

增加“仅显示当前网站验证码”开关。启用后，主界面优先显示与当前访问网站匹配的验证码；关闭后显示全部账号。

## 同步使用说明

1. 在“设置 → 同步与安全”中配置并登录 WebDAV。
2. 开启本地保险库加密，并设置保险库口令。
3. 根据需要开启 WebDAV 自动同步。
4. 日常使用由自动同步负责将本地变更备份到云端；需要主动控制数据方向时，使用“立即上传”或“立即下载”。

**数据方向：**

- 自动同步：本地 → 云端
- 立即上传：本地 → 云端（覆盖云端备份）
- 立即下载：云端 → 本地（覆盖前确认）
