# Vault2FA 魔改版

基于原版 Vault2FA 进行功能调整与增强，当前魔改基础版本：**2.9.8**。

## 魔改内容

### 1. WebDAV 云端同步

将原有同步方式替换为 WebDAV，用户可使用自己的 WebDAV 服务保存加密保险库：

- 支持填写 WebDAV 服务器地址、用户名和密码，登录后即可使用同步功能。
- 本地保险库开启加密后，才允许上传同步数据；上传到 WebDAV 的是加密后的保险库内容。
- **自动同步**：本地新增、编辑或删除验证码后，自动将最新的加密保险库上传到云端。
- **立即上传**：手动将当前本地保险库上传，并覆盖云端备份。
- **立即下载**：手动下载云端备份并覆盖本地保险库，覆盖前会弹出确认提示。
- 提供 WebDAV 登录与退出登录、自动同步开关，以及最近上传和下载状态信息。
- 登录后密码框以掩码形式显示，避免直接展示已保存的密码。
- 修复移动端设置异步刷新时可能清空尚未提交的 WebDAV 密码，导致登录认证失败的问题。
- WebDAV 登录/退出、立即上传/立即下载按钮采用横向并列布局。
- 开启“启用 WebDAV 自动同步”时，如果本地保险库尚未加密，会自动定位到保险库口令输入框；设置口令并点击“应用安全设置”后，先完成本地加密，再自动启用 WebDAV 自动同步。未完成加密前不会提前开启同步。

> 注意：自动同步会同步删除操作，云端备份也会随之更新，因此自动同步不能用于恢复误删的验证码。需要恢复时，应使用仍保留旧数据的其他设备或独立备份。

### 2. 全部设置导入与导出

在设置菜单中，“同步与安全”下方提供两个独立入口：

- **导出全部设置**：将界面语言、主题、当前网站筛选、账号显示选项、功能选项、同步设置、WebDAV 配置、自动锁定设置及调试设置导出为 JSON 文件。
- **导入全部设置**：从 JSON 文件恢复上述设置；导入前会提示确认，导入后重新加载扩展。
- 导入时覆盖对应设置，但**不会覆盖验证码账号数据和本地保险库加密密钥**。
- 如果恢复的设置要求开启自动同步，但当前本地保险库未加密或缺少 WebDAV 凭据，自动同步会保持关闭。
- 导出文件包含 **WebDAV 用户名和密码明文**，请妥善保管，不要上传到公开位置或发送给他人。

### 3. 仅显示当前网站验证码

增加“仅显示当前网站验证码”开关。启用后，主界面优先显示与当前访问网站匹配的验证码；关闭后显示全部账号。点击验证码可尝试自动填入当前网页的输入框；未找到合适输入框时，会将验证码复制到剪贴板。

### 4. 界面与使用体验

- 首次使用默认中文界面，并对已有英文默认设置的旧用户执行一次语言迁移。
- 设置菜单中将“导入全部设置”和“导出全部设置”作为独立一级操作，与“同步与安全”同级。
- 主界面显示同步状态和扩展版本号；点击版本号可打开 Firefox Add-ons 开发者版本页面。
- 移除网页输入框右键菜单中的“在此处打开自动填充弹窗”选项，保留图片右键二维码扫描功能。
- 优化移动端 WebDAV 密码输入体验及设置按钮布局。

## 安装说明

本仓库提供的是魔改源代码，不提供由 Mozilla 签名的安装包。需要自行将构建好的扩展压缩包上传到 [Firefox Add-ons 开发者中心](https://addons.mozilla.org/developers/) 提交签名；签名通过后，下载并安装 Mozilla 签名版本。

也可以在 [扩展版本页面](https://addons.mozilla.org/zh-CN/developers/addon/2d26ddb08f7841948d04/versions) 查看版本及签名状态。

## 同步使用说明

1. 在“设置 → 同步与安全”中配置并登录 WebDAV。
2. 开启 WebDAV 自动同步；如果本地尚未加密，界面会自动定位到保险库口令输入框。
3. 设置保险库口令并点击“应用安全设置”，完成本地加密后自动启用 WebDAV 自动同步。
4. 日常使用由自动同步负责将本地变更备份到云端；需要主动控制数据方向时，使用“立即上传”或“立即下载”。

**数据方向：**

- 自动同步：本地 → 云端
- 立即上传：本地 → 云端（覆盖云端备份）
- 立即下载：云端 → 本地（覆盖前确认）

## 设置备份与恢复

1. 打开扩展设置菜单，选择“导出全部设置”，保存 JSON 备份文件。
2. 在另一份 Vault2FA 安装中选择“导入全部设置”，选取备份文件并确认。
3. 导入完成后扩展会自动重新加载；按需检查 WebDAV 登录状态和自动同步开关。

> 设置备份不包含验证码账号数据，也不包含本地保险库加密密钥。请另外使用 Vault2FA 自身的账号/保险库备份方式保护验证码数据。JSON 设置文件含 WebDAV 明文凭据，务必妥善保管。
